## 审查中发现并修复

1. 新长续航物品只注册不足以完整使用：补齐电池类型校验、轮盘选择、实体安装、NBT 恢复、充电管家与容量识别，兼容旧普通电池的 `LongRangeBattery` 标记。
2. 辅助渲染异常可能残留渲染标志或 GL 状态：用恢复逻辑保证主视角与后续渲染恢复，退出释放辅助缓冲。
3. 辅助渲染 Mixin 的天空方法存在重载匹配风险：指定完整方法签名，避免静态重载导致客户端启动失败。
4. 图传可能显示无人机自身；进入时受第三人称设置影响：隐藏目标本体，图传内部使用第一人称并恢复玩家原设置。
5. 退出飞行后 USB 杆量可能残留：退出时回中，保留原失焦/断连保护。
6. 备用地图缓存可能跨世界复用；虚空或未加载列可能耗尽采样预算：按世界清理，未加载列不扣预算，已加载空列缓存，保持单帧预算上限。
7. RC/4G 地图开关互相耦合：分别控制两个图层，RC 球形覆盖按无人机高度取截面。
8. 小窗口中文字号过大与重叠、部分汉字缺失：按 UI 缩放计算字号，重建字体并检查当前 Java 字符串汉字覆盖。
9. M400 刷怪蛋缺模型：补齐模型文件。
10. 扩大 RC 距离后，自动配对仍限定旧距离：搜索范围改用服务器同步的 RC 距离。

## 功能边界

目标版的拍照、录像、相册、航点，以及部分相机/飞行设置原本只维护 UI 状态。本次保留这些界面交互，没有把它们描述为真实文件输出、完整航点任务或已接入服务器的全部设置。实际飞行控制、云台、档位、辅助图传、电池、充电、信号与地图按上述实现运行。

未连接实体外置遥控器，也未在独立多人服务器执行端到端测试。集成服务器测试涵盖真实服务器物品、实体、网络与存档路径，但不能替代这两项实测。

## 开始开发

在本目录打开 PowerShell：

```powershell
.\gradlew.bat build
.\gradlew.bat genSources
.\gradlew.bat runClient
```

首次运行会下载依赖及游戏资源，需要联网。无需全局安装 Gradle。
本机启用了 Windows 系统代理，而 Java 默认不继承它。推荐使用 `.\dev.ps1 build`、`.\dev.ps1 genSources`、`.\dev.ps1 runClient`：脚本会将当前系统代理传给 Gradle，仅对这次进程生效，不修改全局设置。
若 PowerShell 阻止脚本，可执行 `powershell -ExecutionPolicy Bypass -File .\dev.ps1 build`。
Gradle 支持由本机 Java 21 启动；编译和开发游戏进程由 Java toolchain 使用 JDK 17。
本机 JDK 17 位于 `C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot`。

IntelliJ IDEA：打开本目录，作为 Gradle 项目导入，Project SDK 选择 JDK 17，Gradle 使用 Wrapper。
同步后使用生成的 Minecraft Client 运行配置，或直接执行 `runClient`。
如果换电脑后找不到 Java 17，请先安装 JDK 17，再同步 Gradle。

## 调试现有无人机

开发客户端中创建创造模式世界，允许作弊，执行：

```mcfunction
/summon djimod:avata360 ~ ~1 ~
/give @s djimod:avata360_spawn_egg
/give @s djimod:avata360_battery
```

空手右键无人机可切换相机模式。手持 RC 2 右键无人机连接，左键断开连接。
Shift＋右键已降落且锁定电机的无人机，将整机收入背包（手持 RC 2 时同样有效），不再直接拔出电池。电池仍在机内；收起后通过物品轮盘关机、拔出电池。背包满时拒绝收起，不会删除飞机。重新放置保留名称、电池数据与飞机 UUID；同 UUID 已存在时为副本分配新 UUID。
拿起遥控器或连接成功后保留正常游戏视角；已连接时按鼠标中键进入飞行界面，ESC 退出。

### 鼠标遥控

- 图传以客户端帧率刷新，世界渲染最高 60 FPS，HUD 不锁帧；镜头航向使用浮点同步并在帧间插值，避免原版实体角度量化造成细打杆时跳动。三款无人机的位置每 tick 同步一次。更高的图传刷新率会增加 GPU 负载，实际流畅度仍受客户端帧率和服务端 TPS 影响。

- 遥控界面自动释放鼠标，点击只作用于遥控器，避免攻击、放置或使用世界中的物品。

### DJI RC-N1 USB 遥控

模组客户端直接读取 DJI USB VCOM，不需要启动外部模拟器、Python、`vgamepad` 或虚拟 Xbox 手柄。先安装 DJI Assistant 2 消费级无人机系列驱动，然后开机并使用遥控器底部 USB-C 口连接电脑；启动 Minecraft 后，模组会自动扫描 `DJI USB VCOM For Protocol` 并在连接后读取摇杆。

- Mode 2 左摇杆：左右偏航、上下升降；右摇杆：左右横滚、上下俯仰。
- 手柄需在游戏窗口聚焦时操作；进入/配对、启动、急停、返航等离散操作仍可使用界面按钮或原有键鼠绑定。
- 断开 USB 或遥控器后控制输入会在 0.5 秒内失效并回中，客户端会继续扫描以便重新连接。

直接串口协议读取 38 字节摇杆报告及 58 字节扩展按键报告，基于 RC-N1 / RC231 DUML 通道格式。RC-N2 等系列如果提供相同的 `DJI USB VCOM For Protocol` 和兼容报告，也可使用；其他固件/协议尚未有真机验证。连接状态可在客户端日志中搜索 `avatadrone/rcn`。
- RC-N 按键：右侧 B3 短按切换定速巡航；B2 长按 0.5 秒返航，短按急停；左侧 Fn 在云台回中与朝下 90° 间切换；云台波轮左右拨动控制俯仰；三档开关对应 C/N/S。B1 保留拍摄键用途，目前不会生成照片文件。
- 拖动屏幕左下摇杆：上/下升降，左/右偏航。拖动右下摇杆：前后飞行、左右侧飞。
- 虚拟摇杆松开回中，窗口失焦或退出界面时清零；键盘 Mode 2 控制仍然可用。
- 点击顶部 C/N/S 切换飞行档位，滚轮调整手动杆量 1%–100%。
- 遥控器屏幕上方的实体拨钮支持点击／拖动：C 在左、N 在中、S 在右，位置与当前档位同步。旁边的返航／急停键短按关闭电机，长按 0.5 秒返航；长按松开后不会再触发急停。
- 键盘 S 立即后退，不再通过短按／长按区分后退和运动档，避免摇杆先动再回中的抖动。C 切平稳、N 切普通、Ctrl＋S 切运动，也可以直接使用拨钮。
- Q 或空格上升，E 或左／右 Shift 下降；同时按两个上升键不叠加速度，上下同时按则回中。这些按键在飞行界面内不触发玩家跳跃、潜行等动作。
- 点击 TAKEOFF 自动解锁并上升至离地约 1.2 米；飞行中该按钮显示 LAND，点击自动降落。
- 点击 RTH 返航；点击 STOP 立即关闭电机（空中会坠落）。
- ESC 退出遥控并恢复游戏视角，手持遥控器按中键重新进入。退出后若继续手持已配对 RC，会发送回中输入保持连接；断开连接、更换物品或失联则仍按飞控规则返航。
- 连接/更换连接：正常游戏视角中用 RC 右键无人机；左键断开且不攻击。飞行界面内左键用于操作控件，需先按 ESC 返回游戏视角再断开。

鼠标只能同时拖动一个虚拟摇杆，可与键盘组合使用。拍摄、回看等尚未实现的功能仍是状态显示。

### 避障雷达

飞行界面中心右下方显示四分区圆环雷达：上、下、左、右分别对应机头前方、后方、左侧、右侧；距离越近颜色由绿色过渡到橙色和红色。C（平稳）和 N（普通）档启用机型对应的水平/垂直传感器，任意有效方向距离小于等于 0.5m 时自动硬刹停；S（运动）档显示“已关闭”，不会执行避障减速或刹停。

不同实体覆盖不同传感器范围：Avata 360 使用水平全向视觉范围，Mini 4 Pro 的前/后/侧向范围分别为 18/15/10m，Matrice 400 使用 100m 环向雷达并额外支持上下避障。距离由服务端射线检测同步到 RC2 客户端，断线或切换机型不会复用上一架飞机的数据。

`src/main/java/com/example/avatadrone` 包含注册、实体、客户端模型与渲染代码。
模型、贴图、动画位于 `src/main/resources/assets/djimod`。
修改依赖版本使用 `gradle.properties`；模组入口及加载约束位于 `fabric.mod.json`。

## 构建与安装

### Redmi K90 Pro Max 手机

创造模式 DJI 分类中可找到手机，也可使用 `/give @s djimod:redmi_k90` 获取。

- Shift+右键开机／关机，右键亮屏／熄屏；包含 REDMI、HyperOS 开机动画、关机转圈和关机充电环。
- 桌面显示游戏时间、日期、电量、应用图标和 Dock；亮屏和待机分别消耗电量，耗尽自动关机。
- 对 AURO 2000 ELITE Shift+右键取线，等待抽线完成后，主手拿手机右键电源连接／断开。手机电池为 29.26 Wh，最高输入 100 W；充电时显示电量和桌面充电提示。
- 主手拿手机后，可用 `/redmi app add compass`、`/redmi app remove compass`、`/redmi app list`、`/redmi app reset` 管理桌面；`add <id> dock` 添加到底栏（最多 4 个，桌面最多 20 个）。应用目前提供图标布局，不包含拨号、浏览网页等独立应用界面。

模型与全部配套贴图、动画来自 `model/phone/redmi_k90`。独立测试任务为 `./dev.ps1 runPhoneQa`，使用 `run-phone-qa` 测试世界，需先在该目录创建名为 `Phone QA` 的世界；截图和结果保存在该运行目录。

`build/libs/dji-avata-drone-2.0.1.jar` 是重映射后的发布包；对外发布包位于
`mod/V2.0.1/DronesJoyrideInterface-1.20.1+Fabric-V2.0.1.jar`。不要把 `-sources.jar` 当模组安装。
普通游戏实例需要 Minecraft 1.20.1、Fabric Loader，以及单独安装 Fabric API 和 GeckoLib 4.4.9（Fabric 1.20.1）。
开发运行任务自动加载依赖，不用手动复制这些依赖到 `run/mods`。

服务端开发任务：`.\gradlew.bat runServer`。首次启动后需自行阅读并接受 Minecraft EULA，编辑 `run/eula.txt` 再启动。
`run/` 保存开发世界和日志，已排除版本控制。

GeckoLib 通过官方 Cloudsmith Maven 获取，自动引入 mclib 等运行依赖。
请勿同时运行 `genSources` 与其他 Gradle 任务，Windows 下可能发生游戏 JAR 文件占用。
父目录的 Blockbench 原工程及预览资源保持原位。

## 4G 基站和支柱

创造模式 DJI 分类中新增「4G基站模块」和「钢结构支柱」，也可使用：

```mcfunction
/give @s djimod:4g_signal_emitter
/give @s djimod:steel_pillar
```

- 基站放置后发射面朝向放置者，支持北、东、南、西四个朝向。
- 信号仅覆盖基站正面水平方向左右各 22.5°（总开角 45°）；背面和侧面无该基站的 4G 信号。四向基站之间仍存在未覆盖的夹角，各基站以自己的方块中心和朝向分别判定。
- 半径500格（1格=1米），包括高度差；不计算地形遮挡。仅同一维度有效，不要求玩家也位于基站覆盖内。
- RC直连或4G任一可用即可控制；4G可用时遥控器显示4G。离开所有4G覆盖且RC也超距时失联并向起飞记录的返航点自动返航。RC仍有效时继续直连。
- 仍须持有已配对遥控器；玩家离线、切换维度、放下遥控器或超过1秒未收到控制包会触发原有安全返航。
- 基站拆除立即撤销该基站覆盖；基站索引按维度保存，重启或基站区块卸载不影响已放置基站的信号。
- 飞行中的无人机保持附近区块运行，远程配对实体可继续同步。进入遥控器飞行界面后，服务器按无人机位置额外加载并发送远程地形，客户端保留玩家脚下区块并使用独立的图传区块缓存。
- 图传加载半径跟随客户端游戏视距设置（同时受服务器视距和 Minecraft 32 区块上限约束，最低 2 区块），包含方块、光照、方块实体及附近实体同步；每 tick 请求／发送各最多 2 个区块，新地形从近到远逐步出现。
- 飞行跨区块时更新图传范围并释放离开的区块。退出飞行界面、断开配对、切换物品、换维度、离线或失联后停止图传加载并释放缓存；保持飞行的无人机仍由独立飞行区块票支持悬停／安全返航。恢复信号且仍在飞行界面时重新建立图传加载。
- 钢结构支柱保持竖直，随玩家放置时的水平朝向旋转，支持东、南、西、北四向；结构旋转和镜像也会更新朝向。已有支柱保持默认朝向，可拆下重新放置调整。

验证：`./dev.ps1 build` 包含正面／背面／侧面、±22.5°边界、三维500米距离和四朝向共14400个角度样本的覆盖回归测试。
游戏内验收建议：在距玩家500格外放置朝向无人机的基站，保持遥控器配对后确认4G控制；飞出覆盖、拆除唯一基站后确认失联返航；再测试四向基站重叠覆盖与存档重载。

## DJI Mini 4 Pro

创造模式 DJI 分类内有 Mini 4 Pro 手持无人机。旧刷怪蛋保留注册，可通过指令获取：

```mcfunction
/summon djimod:mini4pro ~ ~ ~
/give @s djimod:mini4pro_spawn_egg
/summon djimod:mini4pro ~ ~ ~ {LongRangeBattery:1b}
```

手持 RC 2 右键连接、普通视角左键断开、中键进入飞行界面，ESC 退出。连接、服务器配置的 RC 直连（默认 10000 格）、已有 4G 基站和失联返航复用现有飞控。空手右键切换云台平视/垂直俯拍，图传方向同步变化。

| 档位 | 水平速度 | 上升速度 | 下降速度 |
| --- | --- | --- | --- |
| C 平稳 | 6 m/s | 3 m/s | 3 m/s |
| N 普通 | 12 m/s | 5 m/s | 5 m/s |
| S 运动 | 16 m/s | 5 m/s | 5 m/s |

- 速度按 20 tick/s、1 格约 1 米换算为飞控目标速度。运动档关闭避障，水平超过 12 m/s 或垂直超过 5 m/s 时相应方向不提供主动制动。
- 碰撞射线模拟前视 18 格、后视 15 格、侧视 12 格、上视 15 格、下视 12 格；近地持续下降允许着陆，不会被下视制动悬停锁住。
- 普通电池按 36 分钟、长续航电池按 49 分钟消耗；可安装独立长续航电池 `djimod:mini4pro_battery_long`，兼容旧 `LongRangeBattery` NBT。电量随实体存档保存，HUD 显示服务端电量及当前运动状态下的估计剩余时间。8% 以下进入降落且不允许再次解锁。
- 渲染使用 `model/mini4pro` 中的原始几何、动画和贴图，缩放 0.4、碰撞箱 0.9×0.45；电机解锁后调平机身并转动四片桨叶，姿态合成倾角上限 35°。
- 图传使用附件 82.1° 对角视角换算的 16:9 纵向 FOV，云台支持资源现有的平视与 -90° 俯拍两种姿态。

这是 Minecraft 飞行模拟：没有模拟实际风场、GNSS 测量误差、前视 200 米可探测范围、独立 8 米红外测距噪声或完整相机曝光/录像功能，也不保证实机 ±0.1 米悬停精度。续航里程是由耗电和实际飞行决定，不能直接保证附件实验条件下的 18/25 公里。连续俯仰可使用云台按键；竖拍及完整相机参数控制尚未加入。

## 手持无人机操作轮盘

从 DJI 创造物品栏取出 Avata 360 或 Mini 4 Pro，手持右键打开轮盘，鼠标左键选择，ESC 关闭。新物品默认装有电池、处于关机状态，云台保护罩已安装。

| 状态 | 电源选项 | 电池选项 | 放置 |
| --- | --- | --- | --- |
| 已装电池、关机 | 开机 | 拔出电池 | 禁用 |
| 未装电池 | 禁用 | 安装电池 | 禁用 |
| 已开机 | 关机 | 禁用 | 可用 |

- 电池是独立的三维物品，两种型号均在 DJI 创造物品栏中提供。新无人机自带一块已安装的电池。
- 拔出电池播放第一人称动画，结束后将机内电池 ×1 放回背包。背包满时禁止拆卸；若动画过程中背包被装满，则取消拆卸，电池留在无人机中。
- 安装从背包选择对应型号的一块电池，动画结束后将它移入无人机，背包减少 ×1。创造模式也按此数量结算。过程中该电池被移出背包或数据发生变化时取消安装，不会改用另一块电池。
- 无人机保存完整电池物品，保留自定义名称、剩余电量及 Mini 4 Pro 长续航标记等数据；放置、收起再拆装也保留这些数据。旧版电池数据会兼容读取。轮盘显示背包中对应电池的数量，缺少电池时禁止安装。
- 开机先取下保护罩，再按电源按钮；关机先按按钮，再装回保护罩。每套动作约 3 秒，结束后更新选项状态。
- 操作过程中重复点击无效；切换手持物品、死亡、离线或更换维度会取消尚未完成的操作，不增减电池。
- 放置前先瞄准 5 格内有足够空间的地面，再打开轮盘选择放置。成功后消耗手持无人机，生成已装电池的实体，桨叶保持锁定，之后可用 RC 2 连接。
- 手持物品和电池使用 `/model` 中的三维模型、贴图及电池动画；手持转向、保护罩和电源按钮动作是补充制作的游戏表现。源模型目录保留原样。

```mcfunction
/give @s djimod:avata360
/give @s djimod:mini4pro
/give @s djimod:avata360_battery
/give @s djimod:mini4pro_battery
```

### 智能返航

手动返航与失联返航共用服务端三维 A* 航线规划。返航自动切换 N 档，以最高约 4m/s 沿经检查的航段飞行；分段读取前方地形高度，遇山体、建筑可爬升或左右绕行。检查覆盖机身体积和 0.5m 安全余量，每次前进前重新确认当前航段，路线被新增障碍挡住时停止并重新规划。

规划使用局部约 24m 的前视目标和有限搜索预算，避免在一次服务器 tick 扫描整条远距离航线。未知/未加载区块不当作自由空间；找不到通道时悬停，每 2 秒重试，能够安全爬升时先爬升再规划。此实现为局部三维路径规划，不保证所有复杂迷宫都能找到全局最短路线。

抵达起飞点水平位置上方后，实时检测机身下方的碰撞表面，检查下一段下降通道并下降，确认贴近地面且有支撑后停桨。降落不使用历史起飞高度：新增屋顶、半砖及地面被挖低都会更新实际落点；无可用地面或区块尚未加载时悬停。RC2 警告栏显示爬升、沿航线飞行、降落或受阻状态。紧急停桨仍可立即中断返航。

构建会执行 `returnRouteTest`，验证直达、翻越山体、侧绕墙体、完全受阻和搜索预算耗尽情形。游戏世界中的动态地形、跨区块和精确降落还需要实机联调验证。

### 撞击／进水事故断连

三种无人机共用事故状态：电机运行时实际撞墙、撞顶或以超过 0.12 格/tick 的下落速度碰地，以及机身接触水体，立即停桨并断开控制／图传。正常低速着陆、避障提前刹停不触发事故。普通信号丢失仍按原逻辑返航；事故断连禁止手动和自动返航、重新解锁和配对。

事故只播放一次 Minecraft 爆炸音效、爆炸粒子动画及烟雾，不破坏方块。机体作为损坏残骸保留，受重力下落；事故状态和初始事故坐标写入存档及收起后的飞机物品，换电池、收起再放置不会修复。

遥控器保留配对记录用于显示事故信息，连接指示灯变红。图传显示事故原因、断连 X/Y/Z 坐标和维度；已有本机画面时冻结最后一帧，无缓存时使用暗底。坐标保存在配对遥控器中，机体下落或消失后仍保留，重新配对正常飞机时清除旧事故记录。

独立验收：`dev.ps1 runAccidentQa --console plain --max-workers=4`，使用 `run-accident-qa/saves/Accident QA`。检查三机型撞墙、撞顶、重落地、正常着陆、进水、事故存档、返航／解锁拒绝，以及客户端红灯和事故位置保留。

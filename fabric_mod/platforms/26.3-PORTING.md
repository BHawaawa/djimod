# Minecraft 26.3 构建与移植

26.3 为正式游戏版本。已根据官方版本清单、Fabric Meta API 和 NeoForge
Maven 元数据确认以下依赖，工程使用独立 Gradle Wrapper，不升级现有 1.20.1 工程。

最新发布清单仅包含 NeoForge 26.3。Fabric 26.3 实验目录保留，不参加构建矩阵。

| 组件 | Fabric 26.3（历史实验） | NeoForge 26.3 |
| --- | --- | --- |
| Java | 25 | 25 |
| Gradle | 9.8.2（含 SHA-256 校验） | 9.8.2（含 SHA-256 校验） |
| 构建插件 | Fabric Loom 1.19.4 | ModDevGradle 2.0.148 |
| 加载器 | Fabric Loader 0.20.1 | NeoForge 26.3.0.103 |
| Fabric API | 0.166.2+26.3 | 不使用 |
| GeckoLib | 5.5.7 Fabric 26.3 | 5.5.7 NeoForge 26.3 |

26.3 游戏不混淆，使用游戏原生类名；不需要等候 Yarn 发布。

工程目录为 `platforms/fabric/26.3` 和 `platforms/neoforge/26.3`。
`platforms/common` 直接编译既有的覆盖算法、返航规划、充电指示和姿态逻辑，
运行对应回归测试。共享源码保持单一来源，现有 1.20.1 路径不搬动。

从 fabric_mod 目录运行移植诊断（编译真实的既有源码，不生成发布包）：

```powershell
.\tools\build_matrix.ps1 -Loader NeoForge -Minecraft 26.3 -CompileOnly
```

脚本优先使用 `-Java25Home` 或 `DJI_JAVA25_HOME`，本机还支持自动查找
`.cache/toolchains/jdk-25*`。仅在当前脚本调用期间切换 JAVA_HOME，退出时还原。
没有改动系统 Java 配置。

NeoForge 26.3 当前为 `porting`，尚未通过完整源码编译和游戏内回归。需要迁移的部分：

- 1.20.1 Yarn 名称转为 26.3 原生名称，更新实体、物品数据和网络 Payload API。
- GeckoLib 4 转为 GeckoLib 5 的模型、渲染状态、动画注册接口。
- 重做世界图传、离屏渲染及相应 Mixin，兼顾 26.3 新渲染管线。
- NeoForge 独立入口、注册、事件、联网和元数据适配。
- 迁移 Xaero 可选集成，校验资源包格式和所有资源引用。

按用户最新要求，构建脚本默认仅编译打包，不启动游戏或运行测试。26.3 源码编译仍有错误，当前无法生成该版本 JAR。完成适配并成功编译打包后标记 `compiled`，运行验收记录另行维护。
